# Marketing & Product Analytics Portfolio

<!-- Add when you have them: Tableau Public profile, LinkedIn, email. -->

Three end-to-end analytics projects with a fintech focus. Each starts from a business question and ends with a recommendation, using SQL, Python and Tableau.

| # | Project | The question behind it | Status |
| :---: | --- | --- | --- |
| 1 | [Web & acquisition analytics](project-01-web-analytics/README.md) | Which channels bring users who convert, and where does the funnel leak? | Analysis complete; Tableau dashboard to come |
| 2 | [Email campaign & retention analytics](project-02-email-retention/README.md) | Which campaigns and customer segments drive repeat revenue? | Not started |
| 3 | [Capstone: fintech growth analytics](project-03-capstone-fintech-growth/README.md) | Where should a fintech app spend its next cedi of growth budget? | Not started |

## How each project is laid out

```text
project-NN-name/
├── data/      raw and cleaned datasets, with a data dictionary
├── sql/       the queries behind every number
├── python/    cleaning, analysis and statistical tests
├── tableau/   workbooks and dashboard screenshots
└── README.md  business questions, methodology, key findings, dashboard,
               recommendations, limitations
```

## About the data

The datasets are synthetic. They are built to behave like real marketing and product data, so the methods carry over, but none of the figures describe a real company.
